
### 1. 问题描述

本实验要求从给定的1033个基站数据的 `K_DIST` 值中，使用线性时间选择算法找出特定顺序的元素。具体任务包括：

1. 找出 `K_DIST` 值中的最小值 (第1小)、第5小、第50小以及最大值。
2. 实现两种不同的子问题划分策略：
   * **一分为二**：标准的、基于单个枢轴（pivot）的划分方法。
   * **一分为三**：将教科书的方法改进为“一分为三”的划分方法。
3. 记录并比较两种策略在选择过程中所达到的最大递归深度，以分析其性能差异。

实验数据源于 `02-1 1033个基站数据.xls` 文件。

### 2. 算法设计

为了完成上述任务，我们设计并实现了两种基于快速排序思想的选择算法。核心区别在于分区（Partition）策略。

#### 2.1. 递归深度记录

为了追踪和比较算法性能，我们遵循作业要求，在程序中设置了全局变量。具体来说，我们使用了两个全局变量：`g_current_depth` 用于记录当前递归的深度，`g_max_depth` 用于记录在整个选择过程中达到的最大深度。

在每次递归函数调用时，`g_current_depth` 会增加；在函数返回时，减少。`g_max_depth` 则会随时更新以保存 `g_current_depth` 曾达到的峰值。在每次完整的选择任务开始前，我们会重置这些变量，以确保计数的准确性。

#### 2.2. 标准选择算法 (一分为二)

这是经典的的 `Randomized-Select` 算法。

- **核心思想**：每次随机选择一个枢轴，将数组划分为两个部分：小于等于枢轴的元素和大于枢轴的元素。
- **执行流程**：

  1. 随机选择一个元素作为枢轴。
  2. 使用 `partition` 函数将数组重新排列，并返回枢轴的最终位置 `p`。
  3. 比较目标次序 `k` 与 `p` 的大小：
     - 如果 `k <= p`，则目标元素在左侧子数组中，递归地在左侧子数组中查找。
     - 如果 `k > p`，则目标元素在右侧子数组中，递归地在右侧子数组中查找。

#### 2.3. 改进选择算法 (一分为三)

我们将传统的“一分为二”划分方法改进为“一分为三”策略，旨在优化算法在处理**重复元素**时的表现。

* 核心思想：
  随机选择一个枢轴 $x$，将数组划分为三个逻辑区间：严格小于 $x$、等于 $x$、以及严格大于 $x$ 的部分。
* **执行流程** ：

1. **枢轴选择** ：随机选择一个元素作为枢轴 **$x$**（若采用 BFPTR 则选择中位数的中位数）。
2. **三路划分** ：调用 `partition_3way` 函数进行重新排列，该函数返回两个边界索引 `lt` 和 `gt`，其中 `arr[lt...gt]` 区间内的所有元素均等于 **$x$**。
3. **区间判定** ：
   * 如果目标次序 `k < lt`，则递归地在左侧**小于区**查找。
   * 如果目标次序 `k > gt`，则递归地在右侧**大于区**查找。
   * 如果 `lt <= k <= gt`，说明目标元素恰好在**等于区**中。由于该区间所有值相等，算法可 **直接返回 **$x$**** ，从而提前终止递归。

* 优势：
  这种改进在处理包含大量重复数据（如基站分布在相同坐标或具有相同 $k$-dist 距离）的集合时具有显著优势。它能够一次性排除所有与枢轴相等的元素，避免了这些元素在后续递归中产生的冗余计算，从而有效降低了递归深度并提升了最坏情况下的运行效率。

### 3. 源代码

```python
import pandas as pd
import random
import sys

# 设置递归深度限制
sys.setrecursionlimit(5000)

g_current_depth = 0
g_max_depth = 0

def load_data(file_path):
    try:
        df = pd.read_excel(file_path, engine='xlrd')
        return df['K_DIST'].dropna().tolist()
    except Exception as e:
        print(f"读取文件错误: {e}")
        return None


def common_partition(a, l, r):
 
    if l >= r: return l
  
    # 随机选择枢轴并交换到起始位置
    randIdx = random.randint(l, r)
    a[l], a[randIdx] = a[randIdx], a[l]
  
    x = a[l]
    i, j = l, r + 1
  
    while True:
        # while (a[++i] < x && i < r)
        while True:
            i += 1
            if i >= r or a[i] >= x: break
        # while (a[--j] > x)
        while True:
            j -= 1
            if a[j] <= x: break
  
        if i >= j: break
        a[i], a[j] = a[j], a[i]
  
    a[l], a[j] = a[j], a[l]
    return j # 返回 j

# --- 算法一: 标准选择 ---

def select_2way_recursive(arr, low, high, k):
    """
    k: 当前子数组内第 k 小的排名 (1-based rank)
    """
    global g_current_depth, g_max_depth
    g_current_depth += 1
    g_max_depth = max(g_max_depth, g_current_depth)

    try:
        if low == high:
            return arr[low]

        # 3. 以 x 为基准进行划分
        i = common_partition(arr, low, high) 
        j = i - low + 1 # 计算左半部分（含基准值）的元素个数

        # 4. 判断 k 落在哪个区间
        if k <= j:
            # 目标在左侧部分
            return select_2way_recursive(arr, low, i, k)
        else:
            # 目标在右侧部分
            return select_2way_recursive(arr, i + 1, high, k - j)
    finally:
        g_current_depth -= 1

# --- 算法二: 改进选择 (一分为三 - 扩展相等区逻辑) ---

def select_3way_recursive(arr, low, high, k_idx):
    """
    k_idx: 全局绝对索引 (0-based index)
    """
    global g_current_depth, g_max_depth
    g_current_depth += 1
    g_max_depth = max(g_max_depth, g_current_depth)

    try:
        if low >= high:
            return arr[low]

        # 调用公用分区函数获得一个基准点
        pivot_pos = common_partition(arr, low, high)
        pivot_val = arr[pivot_pos]
  
        # 为了实现“一分为三”，围绕 pivot_pos 向两边扩展找出相等的区间
        lt = pivot_pos
        while lt > low and arr[lt - 1] == pivot_val:
            lt -= 1
        gt = pivot_pos
        while gt < high and arr[gt + 1] == pivot_val:
            gt += 1

        # 判定三个区间
        if k_idx < lt:
            return select_3way_recursive(arr, low, lt - 1, k_idx)
        elif k_idx > gt:
            return select_3way_recursive(arr, gt + 1, high, k_idx)
        else:
            # 命中等于区，直接返回
            return pivot_val
    finally:
        g_current_depth -= 1

# --- 运行入口 ---
def find_kth(arr, k_rank, method='2way'):
    global g_current_depth, g_max_depth
    g_current_depth = 0
    g_max_depth = 0
    arr_copy = list(arr)
  
    if method == '2way':
        res = select_2way_recursive(arr_copy, 0, len(arr_copy)-1, k_rank)
    else:
        res = select_3way_recursive(arr_copy, 0, len(arr_copy)-1, k_rank - 1)
    return res, g_max_depth

if __name__ == '__main__':
    file_path = 'D:\\code\\算法学习\\作业一\\算法设计与分析-编程作业-第2章 分治\\02-1 1033个基站数据.xls'
    data = load_data(file_path)
  
    if data:
        n = len(data)
        k_targets = {"最小 (k=1)": 1, "第5小 (k=5)": 5, "第50小 (k=50)": 50, "最大 (k={})".format(n): n}
        sorted_data = sorted(data)

        print(f"{'任务':<15} | {'k-dist 结果':<15} | {'一分为二深度':<12} | {'一分为三深度':<12}")
        print("-" * 75)
        for name, k_rank in k_targets.items():
            v2, d2 = find_kth(data, k_rank, '2way')
            v3, d3 = find_kth(data, k_rank, '3way')
            print(f"{name:<15} | {v2:<15.6f} | {d2:<12} | {d3:<12}")
```

#### 4.3. 结果分析

1. **正确性分析**：从结果可以看出，两种算法找到的 `k-dist` 值与预先排序后验证的“正确值”完全一致。这证明了我们实现的两种选择算法在逻辑上都是正确的。
2. **时间复杂度分析**：

   平均时间复杂度：$O(n)$
   原理：在平均情况下，随机选择的枢轴能将数组大致分为比例相当的两部分。虽然每次分区需要 $O(n)$ 时间，但递归只进入其中一个子问题。其递推式平均为：$T(n) = T(n/2) + O(n)$。根据主定理（Master Theorem），结果为 $O(n)$。

   最坏时间复杂度：$O(n^2)$原因：如果运气极差，每次随机选到的枢轴都是当前范围内的最大或最小值，且我们要找的元素在另一端。递推式：$T(n) = T(n-1) + O(n)$，这将导致等差数列求和，结果为 $O(n^2)$。
3. **性能分析 (递归深度)**：
   “一分为三”策略的递归深度均小于或等于“一分为二”策略。

### 5.代码优化：

由于上面的算法在最坏情况下时间复杂度为 $O(n^2)$，所以我们可以使用BFPTR算法使其在最坏情况下也是线性时间复杂度

```python
import pandas as pd
import sys

# 设置递归深度限制
sys.setrecursionlimit(5000)

g_current_depth = 0
g_max_depth = 0

def load_data(file_path):
    try:
        df = pd.read_excel(file_path, engine='xlrd')
        return df['K_DIST'].dropna().tolist()
    except Exception as e:
        print(f"读取文件错误: {e}")
        return None

# --- BFPTR 核心：寻找中位数的中位数 ---

def get_pivot_bfptr(arr, low, high):
    """
    递归寻找中位数的中位数作为枢轴 x
    """
    n = high - low + 1
    if n <= 5:
        return sorted(arr[low:high+1])[n//2]
  
    # 1. 分组并找中位数
    medians = []
    for i in range(low, high + 1, 5):
        end = min(i + 4, high)
        group = sorted(arr[i:end+1])
        medians.append(group[len(group)//2])
  
    # 2. 递归调用选择算法找到中位数的中位数
    # 此处调用一分为二逻辑找中位数的“中位数”
    return select_2way_recursive(medians, 0, len(medians) - 1, len(medians) // 2 + 1)


def common_partition(a, l, r, pivot_val):

    # 找到 pivot_val 的下标并交换到起始位置 l
    for idx in range(l, r + 1):
        if a[idx] == pivot_val:
            a[l], a[idx] = a[idx], a[l]
            break
  
    x = a[l]
    i, j = l, r + 1
  
    while True:
        while True:
            i += 1
            if i >= r or a[i] >= x: break
        while True:
            j -= 1
            if a[j] <= x: break
        if i >= j: break
        a[i], a[j] = a[j], a[i]
  
    a[l], a[j] = a[j], a[l]
    return j # 返回基准值最终下标 i

# --- 算法一: BFPTR + 一分为二  ---

def select_2way_recursive(arr, low, high, k):
    """
    k: 第 k 小的排名 (1-based rank)
    """
    global g_current_depth, g_max_depth
    g_current_depth += 1
    g_max_depth = max(g_max_depth, g_current_depth)

    try:
        if low == high:
            return arr[low]

        # 1. 寻找 BFPTR 枢轴
        x = get_pivot_bfptr(arr, low, high)
  
        # 3. 以 x 为基准进行划分
        i = common_partition(arr, low, high, x) 
        j = i - low + 1 # 计算左半部分元素个数

        # 4. 判断 k 落在哪个区间
        if k <= j:
            return select_2way_recursive(arr, low, i, k)
        else:
            return select_2way_recursive(arr, i + 1, high, k - j)
    finally:
        g_current_depth -= 1

# --- 算法二: BFPTR + 一分为三  ---

def select_3way_recursive(arr, low, high, k_idx):
    """
    k_idx: 绝对索引 (0-based index)
    """
    global g_current_depth, g_max_depth
    g_current_depth += 1
    g_max_depth = max(g_max_depth, g_current_depth)

    try:
        if low >= high:
            return arr[low]

        # 1. 寻找 BFPTR 枢轴
        x = get_pivot_bfptr(arr, low, high)
  
        # 调用公用分区
        pivot_pos = common_partition(arr, low, high, x)
  
        # 扩展为“一分为三”的相等区间
        lt = pivot_pos
        while lt > low and arr[lt - 1] == x:
            lt -= 1
        gt = pivot_pos
        while gt < high and arr[gt + 1] == x:
            gt += 1

        if k_idx < lt:
            return select_3way_recursive(arr, low, lt - 1, k_idx)
        elif k_idx > gt:
            return select_3way_recursive(arr, gt + 1, high, k_idx)
        else:
            return x # 命中等于区直接返回
    finally:
        g_current_depth -= 1

# --- 运行入口 ---
def find_kth(arr, k_rank, method='2way'):
    global g_current_depth, g_max_depth
    g_current_depth = 0
    g_max_depth = 0
    arr_copy = list(arr)
    if method == '2way':
        res = select_2way_recursive(arr_copy, 0, len(arr_copy)-1, k_rank)
    else:
        res = select_3way_recursive(arr_copy, 0, len(arr_copy)-1, k_rank - 1)
    return res, g_max_depth

if __name__ == '__main__':
    file_path = 'D:\\code\\算法学习\\作业一\\算法设计与分析-编程作业-第2章 分治\\02-1 1033个基站数据.xls'
    data = load_data(file_path)
  
    if data:
        n = len(data)
        k_targets = {"最小 (k=1)": 1, "第5小 (k=5)": 5, "第50小 (k=50)": 50, "最大 (k={})".format(n): n}
        sorted_data = sorted(data)

        print(f"{'任务':<15} | {'k-dist 结果':<15} | {'一分为二深度':<12} | {'一分为三深度':<12}")
        print("-" * 75)
        for name, k_rank in k_targets.items():
            v2, d2 = find_kth(data, k_rank, '2way')
            v3, d3 = find_kth(data, k_rank, '3way')
            print(f"{name:<15} | {v2:<15.6f} | {d2:<12} | {d3:<12}")
```



#### 结果分析：

BFPTR 的时间复杂度递推公式为：

$$
T(n) \le T(\frac{n}{5}) + T(\frac{7n}{10}) + O(n)
$$

* **$T(n/5)$** 是找中位数的中位数。
* **$T(7n/10)$** 是最坏情况下，剩下需要处理的元素（即 **$n - \frac{3n}{10} = \frac{7n}{10}$**）。
* 由于 **$\frac{1}{5} + \frac{7}{10} = \frac{9}{10} < 1$**，根据**主定理**或递推分析，该算法可以保证在 **$O(n)$** 内完成。
